# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older | No |

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's private vulnerability
reporting:

https://github.com/RobeyBeswick/plansentry/security/advisories/new

Please do not open a public issue for a suspected vulnerability. Include the
affected version, a description of the impact, and reproduction steps or a proof
of concept. Do not include real credentials, customer data or production state.

Reports will be acknowledged and investigated on a best-effort basis. A fix and
coordinated disclosure will be arranged according to severity and impact.

PlanSentry guards against accidental destructive changes. It is not a sandbox
against a malicious agent, and bypasses of its intended protections are still
security-relevant.
